# 设计

- `researcher` 与 `debate` 各允许 4,000 tokens，`judge` 允许 8,000 tokens；这些上限远高于当前 schema 的实际需要，但避免向中转声明 128,000 tokens。
- 使用 AI SDK `streamText + Output.object` 接收流式响应，服务端等待完整对象并继续沿用 Zod 校验。
- 关闭 SDK 内部的快速重试，复用项目的重试器执行最多两次退避重试，间隔约 15 秒和 30 秒。
- 记录每个阶段的开始、成功、失败、耗时、attempt 和 token，用于区分连接失败、生成超时和结构校验失败。
- 命令行批量工具不再执行启动期遗留任务恢复；该恢复只由主服务启动时负责。命令行可通过参数限制到指定候选。
